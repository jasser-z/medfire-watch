# Demo

1. Run scripts/08_run_all_local.py.
2. Open http://127.0.0.1:8501.
3. On Fire danger, select a place, inspect current weather and toggle satellite heat observations.
4. Open Live camera to test visible fire/smoke detection, then inspect snapshot delivery in Alerts.
5. Use Test for an image or video.

Explain that satellite heat observations are not confirmed incidents and weather danger is not ignition probability. The satellite background mosaic is dated.

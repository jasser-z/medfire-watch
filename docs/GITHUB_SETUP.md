# GitHub Repository Setup

This document provides the exact metadata, topic tags, and release commands needed to
configure the MedFire Watch GitHub repository page for discoverability.

## Repository description

Use this exact description (≤ 350 characters):

> Wildfire and smoke detection with YOLOv8, NASA VIIRS satellite hotspots, Copernicus fire-weather danger maps, live browser camera monitoring with Telegram alerts, and video analysis. Built with FastAPI, Streamlit, MapLibre GL JS and PyTorch.

## Repository topics

Apply these 15 topics via Settings → General → Topics, or run:

```sh
gh repo edit jasser-z/medfire-watch \
  --description "Wildfire and smoke detection with YOLOv8, NASA VIIRS satellite hotspots, Copernicus fire-weather danger maps, live browser camera monitoring with Telegram alerts, and video analysis. Built with FastAPI, Streamlit, MapLibre GL JS and PyTorch." \
  --add-topic wildfire-detection \
  --add-topic smoke-detection \
  --add-topic yolov8 \
  --add-topic object-detection \
  --add-topic satellite-imagery \
  --add-topic nasa-firms \
  --add-topic fire-weather \
  --add-topic telegram-bot \
  --add-topic fastapi \
  --add-topic streamlit \
  --add-topic maplibre \
  --add-topic pytorch \
  --add-topic computer-vision \
  --add-topic deep-learning \
  --add-topic real-time-detection
```

## Social preview image

Upload `docs/media/social-preview.png` (1280×640 px) via Settings → General → Social preview.

The image is generated by `scripts/make_social_preview.py` using Pillow. It contains only
project text, metrics and decorative geometry; no EOX, OSM or third-party map imagery.

## Website URL

Set the repository website URL to the dashboard address if publicly hosted,
or leave blank for a local-only project.

## Release preparation

When ready to tag and publish v0.1.0:

```sh
gh release create v0.1.0 \
  --title "v0.1.0 — Security, Performance & Documentation Audit" \
  --notes-file docs/RELEASE_NOTES_v0.1.0.md \
  --draft
```

Review the draft release on GitHub before publishing.

## Manual checklist

Before the first public release, verify:

- [ ] Repository description is set (see above).
- [ ] All 15 topics are applied.
- [ ] Social preview image is uploaded via Settings → General → Social preview.
- [ ] Website URL is set (if applicable).
- [ ] `README.md` and `README.fr.md` render correctly on the repository page.
- [ ] All badge links (CI, Python version, License) resolve correctly.
- [ ] `CONTRIBUTING.md` and `CHANGELOG.md` are linked from the README.
- [ ] `LICENSE` file is present and recognized by GitHub as AGPL-3.0.
- [ ] `docs/RELEASE_NOTES_v0.1.0.md` is ready for the draft release.
- [ ] The draft release is reviewed and published.
